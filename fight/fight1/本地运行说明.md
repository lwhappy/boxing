# Dual Impact 本地运行说明

这是一个基于 three.js + TypeScript + Vite 的 3D 拳击对战游戏：你控制黑方，红方由机器人自动控制。

## 环境要求

- Node.js 20 或更高版本（推荐 22）
- pnpm（安装：`npm install -g pnpm`），也可以用 npm

## 运行

```bash
pnpm install      # 安装依赖
pnpm dev          # 启动开发服务器，浏览器打开终端里显示的地址（默认 http://localhost:5173）
pnpm build        # 类型检查 + 生产构建，输出到 dist/
pnpm preview      # 本地预览构建结果（http://localhost:4173）
pnpm test         # 单元测试（碰撞、命中去重、出拳距离求解、调参）
pnpm smoke        # 先 build，再用无头浏览器跑完整对战测试（需先执行 npx playwright install chromium）
```

## 直接部署

压缩包里的 `dist/` 已经构建好，可以直接上传到任何静态网站托管（Nginx、GitHub Pages、Netlify、Vercel、对象存储等）。

注意：要通过 HTTP 访问，不能双击 `index.html` 用 `file://` 打开，否则浏览器会阻止加载模型。最简单的本地方式：

```bash
npx serve dist
```

## 目录结构

| 路径 | 作用 |
| --- | --- |
| `public/models/fighters.glb` | 两个人物和全部 10 个动作（由你提供的 all2.glb 优化而来，贴图压缩为 2048px WebP） |
| `src/game/actions.ts` | 按钮和动作片段的对应关系、快捷键（Idle/Guard 对换、Hit React 不显示按钮都在这里配置） |
| `src/game/rig.ts` | 从 GLB 中拆出两个角色、统一骨骼名称、把动作重定向到两个角色 |
| `src/game/fighter.ts` | 人物控制：尺寸归一、动作混合、朝向对手、出拳前自动调整位置和角度、受击反应 |
| `src/game/reach.ts` | 采样每个出拳动作的拳头轨迹，求出能打中头部/躯干的距离和角度 |
| `src/game/anchors.ts` | 每根骨骼上的锚点（胶囊体/球体）和拳头锚点，以及半透明显示 |
| `src/game/combat.ts` | 扫掠球与胶囊体的碰撞检测、命中去重（一次出拳只算一次、不会打到自己） |
| `src/game/ai.ts` | 红方机器人的走位、出拳选择、连击和反击 |
| `src/game/fx.ts` / `src/game/sfx.ts` | 命中特效（闪光、星芒、冲击环、火花）和合成的击打音效 |
| `src/game/arena.ts` / `src/game/camera.ts` | 擂台、灯光，以及自动取景的镜头（拖动旋转、滚轮/双指缩放、双击复位） |
| `src/game/config.ts` | 所有可调参数（出拳速度、击退、机器人节奏、特效强度、镜头等） |
| `src/ui/controls.ts` | 舞台下方的按钮、开关和 Adjust 调整面板 |

## 操作

- 动作按钮：Idle、Guard、Jab、Cross、Cross II、Lead Hook、Rear Hook、Lead Upper、Rear Upper
- 键盘：`Q` Idle，`E` Guard，`1`–`7` 七种出拳，`←/→`（或 `A/D`）后退/前进
- 开关：Robot（机器人是否自动出招）、Auto Reach（出拳前自动调整距离和角度）、Anchors（显示锚点）、Adjust（调整双方位置/旁移/旋转/缩放，Reset 恢复默认）
- Hit React 受击动作在被打中时自动播放

## 更换模型

把新的 GLB 放到 `public/models/fighters.glb` 即可。如果角色节点名或动作名不同，需要同步修改 `src/game/game.ts` 里的 `CHARACTER_NODES` 和 `src/game/actions.ts` 里的 `clip` 名称。
